# PuppyGraph 실데이터 그래프

주소: http://127.0.0.1:5186/puppygraph

보기 방식은 두 가지다.

- **전체 연결:** 구현된 모든 관계 종류의 실제 레코드를 조회한다. 객체 타입을 그린 모델 다이어그램이 아니다.
- **한 객체의 모든 연결:** 선택한 실제 객체에 직접 들어오거나 나가는 관계를 모두 조회한다. 검색 결과 선택, 노드 더블클릭, `이 객체의 모든 연결` 버튼으로 중심 객체를 바꾼다. 이웃의 이웃을 자동으로 포함하지 않는다.

두 방식 모두 관계 종류를 고르는 절차나 암묵적인 날짜 제한이 없다. 정방향·역방향 탐색에서 원래 화살표 방향을 유지하고, 같은 두 객체 사이에서도 원본 관계 키와 역할이 다르면 서로 다른 선으로 그린다. 속성의 정확한 금액 문자열을 그대로 표시한다.

데이터가 많으므로 한 요청에서 관계 종류마다 최대 20개씩 가져온다. `남은 연결 이어보기`는 기존 그래프에 다음 레코드를 추가한다. 남은 데이터가 있으면 반드시 `일부 연결 표시 중`으로 표시한다. 모든 관계의 끝을 확인해야 `구현된 관계 조회 완료`가 된다. 구현 보류 관계는 제외된 개수를 따로 표시한다. 연결이 없는 단독 객체는 전체 연결 화면에는 나타나지 않는다.

일봉은 전체 871만 건을 정렬하지 않고 증권별로 순회한다. 한 증권의 기록을 끝까지 가져온 후 다음 증권으로 진행하므로 과거 날짜가 누락되지 않는다. 전체 DB를 한 번에 모두 브라우저에 적재하는 기능은 아니다. 이어보기를 많이 하면 SVG 노드가 누적되어 브라우저 성능이 저하될 수 있다.

클라우드 PuppyGraph의 읽기 전용 Bolt 조회만 실행한다. 서버의 기존 AWS/SSM 연결을 재사용하며 스키마나 원본 데이터를 수정하지 않는다. 호출별 실시간 조회이며 여러 이어보기 요청 사이의 DB 스냅샷은 고정하지 않는다. 도중에 원본 데이터가 변경되면 해당 보기 버튼으로 새로 조회해야 한다. 실패하면 기존 그래프와 선택한 보기 방식을 보존한다.

검증 명령:

```powershell
$env:PYTHONPATH='apps/entity-workbench'
.cache/news-filter-benchmark/Scripts/python.exe -X utf8 -m unittest discover -s apps/entity-workbench/tests -p test_puppygraph_viewer.py
node apps/entity-workbench/tests/puppygraph-viewer-smoke.cjs
```

브라우저 검증은 5186 포트의 서버와 실제 클라우드 연결이 필요하다. 두 보기 방식, ETF의 여러 관계 종류, 이어보기 누적, 노드 이동, 장애 시 그래프 보존, 모바일 너비를 확인한다. 결과와 화면은 `output/puppygraph-viewer-20261005/`에 저장한다.
