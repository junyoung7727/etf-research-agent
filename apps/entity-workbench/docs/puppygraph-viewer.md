# PuppyGraph 실데이터 그래프

주소: http://127.0.0.1:5186/puppygraph

보기 방식은 두 가지다.

- **전체 연결:** 구현된 모든 관계 종류의 실제 레코드를 조회한다. 객체 타입을 그린 모델 다이어그램이 아니다.
- **한 객체의 모든 연결:** 선택한 실제 객체에 직접 들어오거나 나가는 관계를 조회하고, 중심 객체만 펼쳐서 시작한다. 검색 결과 선택 또는 `이 객체의 모든 연결` 버튼으로 중심 객체를 바꾼다. 하위 객체를 클릭할 때마다 그 객체의 직접 연결을 추가 조회한다. 이웃의 이웃을 자동으로 포함하지 않는다.

두 방식 모두 관계 종류를 고르는 절차나 암묵적인 날짜 제한이 없다. 정방향·역방향 탐색에서 원래 화살표 방향을 유지하고, 같은 두 객체 사이에서도 원본 관계 키와 역할이 다르면 서로 다른 선으로 그린다. 속성의 정확한 금액 문자열을 그대로 표시한다.

전체 연결 화면은 타입을 접어서 시작한다. 회사·주식·ETF·조직은 탐색 시작 타입이므로 클릭해서 불러온 개별 객체를 펼칠 수 있다. 뉴스·공시·일봉 등 하위 타입은 자체 클릭으로 전체 레코드를 펼칠 수 없다. **주식 타입 → 개별 주식 → 선택한 주식에 연결된 뉴스** 순서로 접근한다. 타입 사이 및 개별 객체와 접힌 타입 사이의 선은 불러온 실제 관계의 요약이다. 표본에 없는 관계를 추정해서 그리지 않는다.

개별 객체를 처음 클릭하면 타입과 ID로 직접 연결을 조회하고 해당 객체의 이웃만 펼친다. 다시 클릭하면 접힌다. 접힌 부모를 통해서만 보였던 하위 가지도 함께 사라진다. 같은 뉴스를 여러 종목이 공유하면 원본 ID 기준 하나의 노드로 표시하며, 다른 열린 종목을 통해 도달할 수 있는 뉴스는 유지한다. 같은 화면에서 다시 펼칠 때는 이미 조회한 연결을 재사용한다. 중심 객체나 보기 방식을 바꾸면 캐시와 펼침 상태를 초기화한다.

점선은 화면에서의 타입 소속이고 업무 관계가 아니다. 실선은 실제 관계이며 접힌 끝점은 관계 종류·방향·역할별로 묶어 표시한다. 선을 선택하면 개별 관계와 원본 속성을 확인할 수 있다. 시작 타입의 숫자는 그 묶음에 포함된 불러온 객체 수이고, 하위 타입의 숫자는 아직 접혀 있는 객체 수이다. 어느 숫자도 전체 DB 건수는 아니다.

한 요청에서 관계 종류마다 최대 20개씩 가져온다. 상단의 `남은 연결 이어보기`는 현재 전체/중심 객체 조회 범위에 레코드를 추가한다. 개별 객체 상세의 `이 객체의 남은 연결 불러오기`는 해당 객체의 독립된 이어보기 위치를 사용한다. 중심 객체의 두 버튼은 같은 이어보기 위치를 공유한다. 남은 데이터가 있으면 일부 조회라고 표시하며, 완료는 해당 조회 범위에 대해서만 선언한다. 구현 보류 관계는 제외된 개수를 따로 표시한다. 연결이 없는 단독 객체는 전체 연결 화면에는 나타나지 않는다.

렌더러는 로컬에 고정한 **vis-network 10.1.2**이다. Canvas, 물리 기반 배치, 드래그, 확대·축소, 부드러운 화면 이동을 사용한다. 네트워크 CDN에 의존하지 않는다. 접기·펼치기에서는 기존 노드의 위치를 유지하고 새 이웃을 선택한 객체 부근에 추가한다. 키보드 탐색 목록에서도 같은 동작을 실행할 수 있다. 패키지 출처·무결성·라이선스는 `frontend/vendor/README.md`에 기록한다.

일봉은 전체 871만 건을 정렬하지 않고 증권별로 순회한다. 한 증권의 기록을 끝까지 가져온 후 다음 증권으로 진행한다. 전체 DB를 한 번에 적재하는 기능은 아니며, 가지를 많이 펼치면 Canvas에서도 노드 수에 따라 성능이 저하될 수 있다. 최초 클라우드 조회 시간은 이번 렌더러 변경으로 단축되지 않는다.

클라우드 PuppyGraph의 읽기 전용 Bolt 조회만 실행한다. 서버의 기존 AWS/SSM 연결을 재사용하며 스키마나 원본 데이터를 수정하지 않는다. 호출별 실시간 조회이며 여러 이어보기 요청 사이의 DB 스냅샷은 고정하지 않는다. 도중에 원본 데이터가 변경되면 해당 보기 버튼으로 새로 조회해야 한다. 실패하면 기존 그래프와 선택한 보기 방식을 보존한다.

검증 명령:

```powershell
$env:PYTHONPATH='apps/entity-workbench'
.cache/news-filter-benchmark/Scripts/python.exe -X utf8 -m unittest discover -s apps/entity-workbench/tests -p test_puppygraph_viewer.py
node apps/entity-workbench/tests/puppygraph-viewer-smoke.cjs
node apps/entity-workbench/tests/puppygraph-groups.cjs
node --test apps/entity-workbench/tests/puppygraph-exploration.cjs
```

실데이터 브라우저 검증은 5186 포트의 서버와 실제 클라우드 연결이 필요하다. 타입을 열어도 뉴스가 열리지 않는지, 특정 종목을 열면 그 종목에 연결된 뉴스만 나타나는지, ETF 보유 구성종목 속성과 이어보기, 장애 시 그래프 보존, 모바일 너비를 확인한다. 결과와 화면은 `output/puppygraph-instance-20261005/`에 저장한다.

`puppygraph-exploration.cjs`는 부모 없는 하위 레코드 차단, 종목별 이웃 분리, 공유 노드의 동일성, 상위 접힘 전파, 방향·역할·관계 ID 보존을 검증한다. `puppygraph-groups.cjs`는 API 응답을 테스트 데이터로 대체하고 실제 Canvas를 클릭한다. 객체별 조회와 이어보기, 실패 후 재시도, 캐시 재사용, 원본 값, 중심 객체, 드래그·확대, 모바일을 검증한다. 두 테스트는 실데이터 검증과 구별한다.
