# 기본 질문의 목적 적합 사용 평가

2026-10-05. 현재 13개 CQ 전체가 아니라 객체 그래프가 제공해야 할 기본 조사 능력을 확인했다. 근거는 `basic-cq.json`이다. 질문에는 구현 이름을 넣지 않으며 아래 대응은 평가자 기록이다.

| 기본 질문 | 실제 검증한 답 | 목적에 필요했던 사용 |
|---|---|---|
| 분석 시점까지 확인 가능한 방산 ETF의 보유 기업과 비중은? | 2026-10-05 09:00 KST 기준 10월 1일 구성 10개. 10월 2일 자료는 해당 시점 가용 조건 미충족 | ETF→보유 기록→주식→발행회사. 날짜별 비중과 기업 식별 |
| 그 종목들의 같은 기간 가격·거래량과 조정 기준은? | 10개 종목의 관측 210개를 일괄 조회, SQL과 값 일치 | 주식의 일봉 연결. 가격 원인·기여도는 추정하지 않음 |
| 보유 기업이 공급자로 참여한 계약 발표는? | 역할·사건 유형·가용 시점을 만족하는 참여 기록 456개 | 회사 참여 링크와 사건 속성. 단순 언급을 참여로 대신하지 않음 |
| 선택한 계약 사건의 뉴스 근거는? | 선택한 사건 20개의 근거 20개 일치 | 뉴스의 사건 근거 연결. 실제 자료 확인 |
| 한화에어로스페이스의 원가 구조·영업 레버리지를 계산할 자료가 있는가? | 재무지표 124개에 매출·영업이익·주당 지표는 있으나 원가 구분·생산량 없음 | 회사 재무지표와 기간·회계·도출 방식. F01 계산 보류의 근거 |

목적에 기여한 객체는 ETF, ETFHolding, Equity, Company, DailyBar, SourceEvent, NewsArticle, FinancialMetric의 8개다. 링크는 보유 ETF, 보유 주식, 발행회사, 주식 일봉, 회사 사건 참여, 뉴스 사건 근거, 회사 재무지표의 7개다. 다른 타입의 통합 검사는 이 질문의 사용 점수에 더하지 않는다.

**80% 달성으로 판정하지 않는다.** 8/23이나 7/37은 종류의 단순 비율이며 사용자가 정의한 데이터 사용 커버리지가 아니다. 평가할 대상·기간의 실제 데이터 범위와 각 사용의 목적 적합성을 고정하고 에이전트 실행별 근거 추적을 수집해야 한다. 이번 실행은 결정론적 질의이며 에이전트의 자유 경로 선택을 시험하지 않았다.

CQ-05·06의 전망/가격 설명 전체, CQ-07의 금액·제품 등 특징 조건, F01 상세 8개 질문은 모두 통과한 것이 아니다. F01 자료 부재는 기업의 원가 구조가 나쁘다는 뜻이 아니다. 매출총이익률을 공헌이익률로 대신 쓰거나 매출·이익 동행만으로 영업 레버리지 계수를 만들지 않는다.
