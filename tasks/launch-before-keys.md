# API 입력 직전까지 구현 · 2026-09-16

사용자 최신 지시가 커뮤니티 제외 결정을 대체한다. 원본의 커뮤니티·글·댓글·반응·투표·개인 프로필을 복원한다. 로그인과 알림 제외, 국내 상장 ETF 범위, 원본 디자인·모션은 유지한다. 커뮤니티는 명시된 예시와 기기 내 체험 데이터이며 방문자 간 공개 게시판은 아니다.

기존 원본 JavaScript/TypeScript 웹앱 + FastAPI 구조를 사용한다. 새로운 화면의 데이터 어댑터가 기존 API 계약을 소비한다. API 미입력 상태는 DEMO이며, live 연결 실패를 예시 금융 자료로 덮지 않는다. 금융·AI 키는 서버 환경에서만 입력한다.

## 실행 단위와 완료 조건

1. 커뮤니티: 원본 목 게시글 표시, 작성·댓글·좋아요·리포스트·투표·삭제·프로필·기기 저장 검증. 다른 브라우저와 격리.
2. 화면/API: 카탈로그·가격·차트·비중·분석·대화 연결. 내부 디자인 키와 종목코드의 명시적 대응. 자료 없음·지연·연결 장애·재시도·분석 진행/실패 검증.
3. 서버: 키 없이 실행되는 공급자 프로토콜 통합 시험. 인증키가 없을 때 외부 호출하지 않음. 키·모드·송신 IP·MCP·예산 설정 점검 명령 제공.
4. 모바일: Capacitor Android·iOS 프로젝트, 서버 주소 설정, 번들 자산과 기본 데모. Android APK 빌드 및 실행 가능한 플랫폼에서 검증. iOS는 실제 macOS 빌드 증거와 프로젝트 생성 여부를 구분.
5. 배포: Docker 이미지·영구 저장소·상태 검사·환경 변수·압축·보안 헤더, 키 없는 서버 실행 검증. 제공 가능한 공개 데모 호스팅을 실행하고 실제 HTTPS URL 점검. 장기 서버는 사용자 호스팅 정보에 맞게 배포 또는 계정 연결 직전까지 준비.

## 검증 경계

외부 모의 서버와 실제 인증된 Kiwoom/DeepSeek/MCP는 구분한다. API 키 미입력 조건에서 실제 시장 접속 성공을 주장하지 않는다. 서명 인증서·스토어 계정이 없으면 배포 가능한 서명본으로 판정하지 않는다. 공개 데모가 제공되더라도 외부 API 서버의 운영 배포 완료와 구분한다.

원본 소스는 수정하지 않고 어댑터를 수정한다. 공급자 프로토콜·결측·오류는 계약 시험, 사용자 동작은 브라우저 시험, 디자인·모션은 기존 원본 비교로 확인한다. 필요한 코드만 앱 디렉터리에 변경하며 루트 연구 작업은 보존한다.
