# EDGE 웹 데모 구현 계획

사용자가 2026-09-16에 경로 A를 선택했다. 국내 상장 ETF, 로그인·알림 제외. 최신 지시로 커뮤니티 목 자료와 기기 저장을 포함했다. 최신 범위는 [launch-before-keys.md](launch-before-keys.md)가 우선한다. 기존 연구 도구와 의존성을 분리한 독립 앱이다.

## 구현 순서와 증거

1. React/TypeScript + Vite 화면과 Python/FastAPI 서버를 같은 출처로 연결한다. `/api/health`와 빌드로 검증한다.
2. 온보딩·홈·검색·관심 그룹·개인 설정을 구현한다. 이름/코드 검색, 그룹 중복 방지·추가/삭제/순서·브라우저 격리·새로고침 보존을 검증한다.
3. ETF 차트·분석 날짜·요인·구성·테마·이슈/출처를 연결한다. 100→103=3%, null≠0, 구성 잔여 비중 보존, 화면 간 스냅샷 일치를 검증한다.
4. Kiwoom REST/WS 수집과 DeepSeek–MCP 도구 실행을 서버에 구현한다. 허용 목록·오류·토큰·시간/예산·부족 자료 처리의 계약 시험을 한다. 자격증명 없는 실제 접속을 PASS로 기록하지 않는다.
5. 모바일 브라우저 전체 흐름·직접 링크·오류·보안·빌드를 검증하고 실행/배포 문서를 제공한다. 공개 서버·API 설정·시세 재제공 근거가 확보되면 외부 실측·공개 배포·디스콰이엇 등록을 이어간다.

## 검증 근거와 제한

- 금융 계산은 직접 검산 가능한 값, 저장은 독립 브라우저 두 개, 사용자 동선은 Playwright 실제 브라우저를 기준으로 한다.
- 외부 API 스펙 시험은 실제 계정 접속 증거를 대체하지 않는다.
- Figma 예시 뉴스·가격·전망을 현실의 현재 정보라고 표시하지 않는다.
- 별도 베타 스토리는 답변 전에는 구현하지 않는다. 전망 점수는 정책 확정 전까지 보류하며 이를 중립 점수로 바꾸지 않는다.
- 공개 배포용 API 설정과 서버는 아직 확인되지 않았다. 루트의 기존 비밀 파일은 이 앱에서 자동 로드하지 않는다.
- 상세 설계와 36개 검증 ID는 `private/demo-spec/`에 있다. 아래 실행 기록은 개별 검증 범위만 뜻하며 전체 공개 준비 완료를 뜻하지 않는다.
