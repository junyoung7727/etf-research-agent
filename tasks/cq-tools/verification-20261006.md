# 그래프 CQ 도구 구현·검증 보고서

2026-10-06 KST. 이번 구현과 재검증의 결과다. 전체 계획 완료 보고서는 아니다.

한 ETF의 전망·가격 설명을 만드는 데 필요한 자료를 PuppyGraph에서 발견하고, 중요한 계산을 저장된 도구 근거로 설명하는 경로를 구현했다. 현재 **29개 도구를 호출할 수 있지만 전체 지원 완료는 아니다.** 최신 실행 기준 13개 CQ는 **통과 3개, 자료 부족 4개, 개선 필요 6개**다. 가장 중요한 전망 CQ05와 가격 설명 CQ06은 아직 통과하지 못했다.

[대시보드: 질문·실제 답변·의미 평가·저장 근거](http://127.0.0.1:5186/benchmark) · [PR #15](https://github.com/junyoung7727/etf-research-agent/pull/15)

## 사용자 의도와 구현 경계

- 새 CQ 도구의 사실 조회는 PuppyGraph만 사용한다. DB 직접 조회는 뷰·매핑 구축과 원본 대조에만 사용했다.
- 사건 수치는 참여 역할과 문서 근거에 연결한다. 출처 개수는 중요도·신뢰도·커버리지의 근거가 아니다.
- 공급계약 업무 객체나 운영 수집 상태를 새 업무 객체로 만들지 않았다. 사건 참여자는 회사·기관 Actor다.
- 명시한 종목 목록과 ETF 전체 보유를 지원하며, 화면 첫 페이지와 전체 계산 자료를 분리한다. 누락을 0으로 바꾸거나 확보한 비중을 100%로 재조정하지 않는다.
- 수익률·NAV 변화·비중 합·비중 차이·수급 합·재무 증감은 저장된 도구 결과를 사용한다. 단순 나열·개수·순서 판단까지 별도 계산 도구를 강제하지 않는다.
- 사실 주장에는 성공한 저장 근거가 필요하다. 미지원·계산 거절을 설명할 때는 그 실패 응답을 한계의 근거로 사용할 수 있다. 참조 검증 통과는 문장의 의미 정확성 보증이 아니다.
- 현재 연결은 실제 v2 실행기에 새 도구를 주입하는 벤치마크 경로다. 고객 분석의 기본 실행 경로는 아직 전환하지 않았다.

## 최신 CQ 판정

| CQ | 목적 | 판정 | 남은 이유 또는 확인 범위 |
|---|---|---|---|
| 01 | 두 ETF의 기업·업종 분산 | 자료 부족 | 지정한 두 번째 ETF 자료가 확인되지 않음 |
| 02 | 거시 전제·가격·NAV·장중/마감 수급 | 개선 필요 | 같은 구성종목의 장중·마감 비교 누락; 검색 안정성 부족 |
| 03 | 신규 계약·변경·재보도 구분 | 통과 | 보도된 첫 계약 근거, 역할·금액·기간 차이 및 후속 한계 확인 |
| 04 | 동일 기간 실적 개선 비교 | 자료 부족 | 전체 재무 비교 가능, 사업부문·정정 호환은 미확인 |
| 05 | 한 ETF의 한 달 전망 | 개선 필요 | 최종 문장에서 기간을 바꾸고 검증하지 않은 영업 레버리지 관계를 사용 |
| 06 | 오늘 가격변동 설명 | 개선 필요 | 과거 이동평균 판단 재사용, 장중 보도 누락 |
| 07 | 역할·특징 조건에 맞는 사건 | 개선 필요 | 공시 기간·실제 체결 기간의 경계와 사례 수 범위 정리 필요 |
| 08 | 이전 설명 이후 바뀐 사실 | 자료 부족 | 요청 기준일까지 이전 설명이 없음 |
| 09 | 사건 당시·현재 보유 여부 | 통과 | 정확한 두 날짜의 저장 보유와 도구 비중 차이 확인 |
| 10 | 전체 구성종목의 방향 분포 | 개선 필요 | 전체 방향·NAV 계산은 확인, 조정 여부 미확인을 미조정으로 서술 |
| 11 | 발표 계획의 실제 진행 | 통과 | 예정·체결·실행 구분; 실행 미발견을 실제 부재로 확정하지 않음 |
| 12 | 발표 전 기대 대비 실적 | 자료 부족 | 같은 기간·회계 범위의 발표 전 기대 관측 없음 |
| 13 | 현재 전망의 반대 근거 | 개선 필요 | 미검증 환율·이익 관계와 중재 진행 상태의 본문·한계 충돌 |

통과도 이 실제 입력과 저장 자료 범위의 판정이다. 모든 산업·시점·반례에 대한 보증은 아니다. 오류가 있는 답변을 고쳐 쓴 결과로 바꿔 저장하지 않았으며, 실제 생성 답변과 검토를 함께 보존했다.

- 최신 커밋 `54bcadc7eddf6d349bd8f549497206edcb9de1d2`의 [CI](https://github.com/junyoung7727/etf-research-agent/actions/runs/37346773690) 통과.
- 대시보드에서 실제 답변·저장 근거·13개 최신 CQ·도구 지원 범위·모바일 가로 넘침을 검사했다. 브라우저 오류 없음.
- ECS에서 CQ07(`114b553`), CQ05(`2c6af9f`), CQ13(`90a1e95`), CQ05(`54bcadc`)를 실제 실행·회수했다. 모두 컨테이너 종료 코드 0이며 임시 그래프 접근 규칙 제거를 확인했다. 실행 성공을 의미 통과로 계산하지 않았다.
- 최신 클라우드 CQ05: 도구 40회, 약 199.9초. 코드 번들 해시 `e832bab1657498a6fb918842fd76716ed6268e6dc53ac086c8e02c69db8148f3`. 기존 v2 이미지에 검증용 코드 번들을 배치한 방식이며 고객 운영 서비스 배포는 아니다.

## 별도 효율 검사

가격 조회→관측 종가 변화→방향 분포의 실제 그래프 검사에서 1·5·30개 종목은 각각 그래프 쿼리 2회였다. ETF 전체 보유 선택을 포함한 10종목 경로는 5회였다. 각 범위 3회 중앙 실행시간은 124.12·121.83·177.30·255.71ms다. 표시 페이지 2행과 전체 계산 집합을 분리해 확인했다.

실제 모델의 30종목 동일 질문은 일괄 해소 추가 전후 도구 호출 **51→7**, 그래프 쿼리 **39→2**, 실행시간 **82.0→31.3초**였다. 개선 전 51회 중 3회는 내부 실행 전 형식 검증에서 거절됐다. 여러 계산 묶음으로 전체를 처리한 경로도 인정했으며 한 경로만 정답으로 강제하지 않았다. 버전별 실제 모델 실행 1회이므로 안정적인 지연 백분위로 해석하지 않는다.

## 80% 커버리지와 남은 작업

**목적 적합 객체·관계 데이터 사용 80%는 미검증이다.** 39개 목적 확인 항목의 충족률, 통과한 CQ 비율, 출처 수, 조회 행 수를 이 커버리지로 바꾸어 말하지 않는다. 실제 사용 자료와 그 자료가 주장·선택·배제·반대 근거 판단에 기여한 근거를 연결한 검토가 더 필요하다.

우선순위는 다음과 같다.

1. CQ05·06의 최종 문장과 근거의 기간·단계·가설 지위를 일치시키는 검증·수정 단계. 설명을 추가하는 것만으로 오류가 사라지지 않았음을 이번 재시험에서 확인했다.
2. 페이지를 읽지 않은 것·검색 실패·원천 부재를 구분하는 탐색 완결성. 주요 기업 재무와 장중 선행 보도를 놓친 사례를 반례로 유지한다.
3. 실제 원천 의존 해결: 비교 가능한 기대 관측, 재무 계산 입력의 판본·원천 연결, 사업부문 기간·회계 범위, 이전 분석의 과거 도구 근거 해소. 그래프가 먼저이며 DB 우회는 허용하지 않는다.
4. 설계와 실행 간 남은 기능: 여러 보유 기준일 일괄 조회, 업종별 ETF 중복 계산, 기존 파생 지표의 새 도구 지원. 현재 지원 범위는 별도 도구 목록에 명시했다.
5. 검증된 도구를 v2 기본 실행 경로에 연결하고 해당 버전으로 클라우드 CQ를 다시 검증한 뒤 전환한다.

OHLC 원천 보완은 사용자가 미룬 항목으로 그대로 남긴다. 장중 누적·구간, 가격 조정 기준, 시장가치 기준일·통화 등 원천에서 확정하지 못한 의미는 임의로 채우지 않는다.
