# ETF 중기 전망: 근거 정책 v0.1

상태: PR 01A 검토안. 새 opt-in 경로에만 적용한다.

## 관측과 판단을 분리

`observation`은 출처에서 읽었거나 코드로 계산한 특성이다. 원문 주장은 `evidence`로 보존한다.
`assessment`만 투자 해석을 담는다. 지표의 증가/감소와 투자상 긍정/부정은 별개다.
‘팩터’라는 표현만으로 raw 값·계산값·회귀 노출·판단 점수를 한 필드에 섞지 않는다.
외부 리포트의 점수는 그 작성자의 방법으로 산출된 관측이지, 새 모델의 정답이 아니다.

## 출처별 허용 범위

| 공급원 | 사용 범위 | 확인 전 가정하지 않을 것 |
|---|---|---|
| 키움 MCP/API | 지원이 확인된 가격, 국내 투자자별 거래 | 모든 미국 ETF 지원, 가격 조정 방식, 미국 주체별 수급 |
| FRED | 설정된 거시 시계열과 메타데이터 | 수정 후 값을 과거에도 알고 있었다는 가정 |
| 운용사 공식 자료 | ETF 식별, 구성종목·비중·기준일 | ETF 기본정보 응답에 보유목록도 포함된다는 가정 |
| TinyFish | 공개 뉴스·리포트 검색 및 접근 가능한 본문 | 제목/검색 요약만으로 본문 확보, 유료 접근 권한 우회 |

새 경로는 FMP를 직접 또는 legacy provider를 통해 우회 호출하지 않는다. 외부 자료는 비신뢰 입력이다.
문서에 포함된 프롬프트·명령·URL·파일경로가 도구 호출이나 정책 변경을 지시할 수 없다.
본문은 허용된 수집기가 확보한 자료만 전달한다. 에이전트 출력으로 실행 경로나 도구 allowlist를 확장하지 않는다.

## 한 주장에 보존할 정보

- 식별: `source_id`, 대상 `entity`, 연결된 ETF/보유종목 식별자, 여섯 축 태그.
- 위치: 원문 URL, 문단/페이지·표/행 위치, 본문 해시, 원출처/재인용 관계.
- 시점: `published_at`, 주장/수치의 `as_of`, `retrieved_at`, 확인 가능한 `available_at`.
- 유형: `reported_fact|source_forecast|source_interpretation`.
- 내용: 원문의 조건·부정·범위와 짧은 발췌. 숫자는 원문 문자열과 단위·통화·기간·정의를 함께 기록.
- 상태: 접근 가능/제목만/접근 실패, 정정·충돌·결측 사유. 확인하지 못한 값은 `null`.

원문이 주장한 사실을 충실히 옮겼다는 것과 현실의 사실로 독립 확인했다는 것은 다르다.
기업 전망·애널리스트 추정은 공식 문서라도 전망이다. 익명 제보·혐의·분쟁은 해당 출처의 주장으로 귀속한다.
개인의 의도·불법행위·성격을 추정하지 않는다. 오너리스크는 공개된 권한·거래·희석·지배구조·집행 사건에 한정한다.

## 시점·정의·결측

조회일을 `as_of`로 대체하지 않는다. 리포트 발행일을 모든 인용 숫자의 기준일로 복사하지 않는다.
현 시점 분석에서 날짜 미상 자료는 맥락으로 표시할 수 있지만 현재성의 핵심 근거로 쓰지 않는다.
과거 시점 replay의 판단 근거는 당시 이용 가능성이 확인된 자료로 한정한다. 확인 불가 자료는 제외 사유를 남긴다.
가격 조정·분배금 포함 여부가 불명확하면 총수익이라고 부르지 않는다. 거래일 수와 달력 개월 수도 구별한다.

배수는 trailing/forward, 분모(이익/매출/EBITDA), 통화·단위·기준일·산식을 맞춘 뒤 비교한다.
분할 전후 가격, 서로 다른 투자자 범주, 다른 기간의 누적 순매수는 같은 계열로 합산하지 않는다.
FRED의 관측 대상일과 발표/개정 시점을 구분하며, 과거 시점 분석에 최신 개정값을 몰래 넣지 않는다.

기본 검색 범위(뉴스 90일, 리포트 180일)는 비용 한도이지 사실의 유효기간 판정식이 아니다.
가격·보유·재무 자료의 오래됨은 각각의 발표 주기와 판단 기간에 비춰 표시한다.
상위 10종목·본문 20개 한도는 기본 설정값이며 적정성과 coverage를 보장하지 않는다.
어떤 보유 비중을 조사했는지와 어떤 축의 자료를 확보했는지는 별도로 보여준다.
누락 보유 비중을 100%로 재정규화하지 않고, 종목 수 비율을 투자 비중 coverage로 부르지 않는다.

## 중복·충돌·반대 증거

같은 보도자료를 인용한 세 기사는 세 개의 독립 확인이 아니다. 원자료 ID를 공유하고 인용 관계를 보존한다.
같은 사건이라는 이유만으로 독립 취재까지 자동으로 합치지 않는다. 원출처 불명은 불명으로 남긴다.
코드는 정확한 URL/해시 중복과 참조를 검사할 수 있지만 의미상 중복·독립성은 모델 판단 후 감사 대상이다.

충돌 처리 순서:

1. 대상·기간·단위·정의가 같은지 확인한다. 다르면 비교 불가 또는 범위 차이로 기록한다.
2. 같은 관측의 공식 정정은 해당 시점 이후의 분석에서 정정값을 우선한다. 구값과 정정 관계도 남긴다.
3. 원자료/직접 문서와 재인용의 차이는 원자료를 우선하되 불명확한 부분은 숨기지 않는다.
4. 해소되지 않은 실질 충돌은 두 값과 이유를 보존하고 결론 범위를 좁힌다. 임의 평균하지 않는다.

반대 방향 검색식을 수집 계획에 포함한다. 부정 기사가 없다는 이유로 만들어 채우지 않는다.
검색하지 않은 상태와 검색했지만 찾지 못한 상태를 구분한다. ‘증거 없음’을 반증으로 쓰려면
그 가설이 맞을 때 해당 정보가 실제로 공개·관측될 이유와 수집 범위가 충분함을 먼저 정당화해야 한다.

## 기존 지침과 충돌할 때

새 경로에서는 이 정책이 다음 legacy 관행을 대체한다. 기존 경로의 파일은 수정하지 않는다.

| Legacy 관행 | 신규 정책 |
|---|---|
| 투자 direction 필수 분류 | 원문 변화·주장 유형과 투자 판단 분리 |
| 기준일 미상 시 조회일 대체 | 기준일 null, 조회 시각 별도 |
| FMP/Toss 우선 수집 | 위의 확인된 공급원만 사용, FMP fallback 금지 |
| 부정 근거 개수 요구 | 반대 검색 이력·관측 한계를 기록, 개수 맞추기 금지 |
| 기존 후보 상태·점수로 결론 표현 | 처리상태와 절대/상대 전망을 별도로 표현 |
