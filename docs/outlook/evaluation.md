# ETF 중기 전망: 평가·승인 명세 v0.1

상태: PR 01A 검토안. 평가를 실행한 결과가 아니다.
이 문서의 목표는 ‘말이 그럴듯함’이 아니라 원문 충실성·관계 구별·유용한 보류를 검사하는 것이다.

## 서로 다른 세 가지 완료

| 게이트 | 완료 증거 | 완료를 뜻하지 않는 것 |
|---|---|---|
| PR 01A 정책 승인 | 사람이 workflow·evidence-policy·이 문서의 판단 규칙을 검토하고 승인 기록 | 모델 리뷰, 문서 링크 검사, PR 생성만으로 승인 대체 |
| 실행 품질 승인 | 고정 자료에서 실제 모델 출력을 원문 대조하고 아래 기준 충족 | 고정 가짜 응답을 통과시킨 배선 테스트 |
| 전망 유효성 검증 | 사전 기록한 전망을 이후 수익·위험과 비교한 전향 평가 | 회고 사례 몇 개의 적중이나 LLM 확신 |

PR 02 이후 구현 전 첫 번째 게이트를 통과해야 한다. PR 병합은 별도의 사용자 결정이며
정책 승인이 병합 허가를 뜻하지 않는다. PR 06B·07A·07B의 모델 평가는 두 번째 게이트를 검증한다.
자료나 권한이 없으면 `not_executed`로 기록하고 통과 건수에 넣지 않는다.

## 초기 사례 목록

[evaluation-cases.json](evaluation-cases.json)은 **18개 사례의 제작 명세/인덱스**다.
본문·시장자료 픽스처와 모델 출력은 아직 없다. 따라서 18개 평가가 준비됐거나 통과했다고 말할 수 없다.
여섯 축별 정상/오해 유발 12개와 변형 6개이며, 개발 12개/미사용 6개를 시나리오 계열 단위로 분리한다.
변형 사례는 원본과 같은 split이어야 한다. 단순한 파일 분리가 정보 누수를 막아주지는 않는다.

모델 실행 전 각 사례에 다음을 채운다.

- 요청: ETF 식별·기간·판단 시각·벤치마크·통화.
- 입력 묶음: 이용 허가된 실제 자료 또는 명시적 합성 자료, 출처/위치/시점/해시, 누락 상태.
- 정답 기준: 허용 결론 범위, 필수 불확실성, 금지 비약, 원문 대조 위치, 수치·참조 정답.
- 실행 기록: 모델/프롬프트/정책 버전·해시, 호출 설정·토큰·시간, 실패/수정 횟수.
- 판정: 기계 검사 결과, 사람 검토자·시각·이유, 치명 오류 목록, 항목별 점수.

미사용 사례의 본문/정답은 프롬프트 조정 담당자가 접근하지 않는 평가자 관리 위치에 보존한다.
이 저장소에는 ID·계열·split·해시/접근 상태와 축·사례 유형·변형 방식 등 공개 제작 메타데이터만 기록한다.
실제 본문·수치·사례별 정답은 공개 인덱스에 넣지 않는다. 합성 입력을 같은 모델로 만들고 보여준 뒤
미사용이라고 부르지 않는다. 노출되거나 그 결과로 튜닝했다면 consumed로 표시하고 새 사례를 만든다.
인덱스의 초기 분할은 작은 범위의 시작점이며 모든 축의 일반화를 입증하지 않는다.

## 통과 규칙

기계적 계약은 필수 필드·참조·단위·수치 변환·시점 적격성·기밀값 검사 100% 통과가 필요하다.
기계가 검증할 수 있는 것을 모델 심사에 맡기지 않는다. 문장이 근거의 의미를 실제로 지지하는지는 별도 대조한다.

다음 치명 오류는 모든 필수 평가 사례에서 0건이어야 한다. 실패 사례를 결과에서 빼고 통과율을 계산하지 않는다.

- 원문 없는 핵심 사실, 잘못된 기업/ETF 연결, 결론을 바꾸는 수치·단위·시점 오류.
- 당시 이용 가능하지 않은 근거를 과거 판단에 사용.
- 거래량을 기관 순유입으로 확정하거나 미확보 보유 비중을 전체로 외삽.
- 재인용을 독립 확인으로 세어 확신 강화, 원출처의 조건·부정을 제거.
- 근거 수/정성 확신으로 수익 확률·목표가를 생성.
- 외부 본문의 지시문을 실행 지시로 수용.

내용 평가는 네 항목을 각 0~2점으로 판정한다.

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 원문 충실성 | 중요한 주장/조건을 왜곡·누락 | 대체로 충실하나 귀속/조건 일부 불명 | 핵심 주장마다 정확한 원문·유형·조건·시점 |
| 관계·대안 구별 | 상관을 인과로 단정, 허수아비 대안 | 타당한 연결/대안 있으나 구별 근거 부족 | 중복·노출·경로·충돌 구별, 강한 대안과 구별할 증거 |
| ETF·기간 관련성 | 기업 소식에서 ETF 전망으로 비약 | 노출/기간 언급하나 한계 불명 | 보유 범위·전달 시차·요청 기간 관련성을 구체적으로 제한 |
| 불확실성·수정 조건 | 결측을 중립화, 확정적 결론 | 한계 설명하나 수정 조건이 모호 | 보류/상반 근거 구별, 대상·시점·판단 변화 조건 명시 |

제안된 실행 게이트는 각 사례에서 모든 항목 1점 이상, 합계 7/8 이상이다. 평균 점수로 개별 치명 오류를 상쇄하지 않는다.
정보 부족 사례에서는 근거 있는 보류가 정답일 수 있다. 부족한 자료로 방향을 냈다고 가점을 주지 않는다.
이 숫자는 초기 운영 기준이며 통계적으로 최적이라고 주장하지 않는다. 정책 승인 때 확정하고 실행 후 임의 완화하지 않는다.

## 변형 평가의 기대 반응

| 변형 | 유지/변화해야 하는 것 |
|---|---|
| 재인용 추가 | 독립 근거 수·확신을 늘리지 않음 |
| 핵심 근거 제거 | 관련 가정의 지지 강도를 낮추거나 보류, 무조건 전망 반전은 요구하지 않음 |
| 공식 정정 | 새 시점 분석은 정정값 반영. 정정 전 replay에는 미래 정정값을 넣지 않음 |
| 기간 불일치 | 비교 가능성/관련성 제한, 다른 기간 수치를 동일 변화율처럼 합치지 않음 |
| 입력 순서 변경 | 경제적 결론·주요 불확실성 유지. 문구나 나열 순서 일치는 요구하지 않음 |
| 무관한 자료 추가 | 전망 방향·핵심 논점이 영향받지 않음 |

위 기대는 의미적 성질이다. 기계로 값/참조를 검사하고, 판단 변화는 사람이 원문과 대조한다.
변형 때문에 실제 가정이 달라졌다면 판정 근거를 남긴다. 단어 일치율로 의미 안정성을 대신하지 않는다.

## 단순 분석과의 비교

기준선은 같은 입력 묶음으로 작성한 ‘여섯 축 관측 요약 + 한 문단 전망’이다.
신규 방식은 여기에 중요 논점·연결·경쟁 설명을 더한다. 모델·자료·총 호출 예산을 맞추고
실제 사용 비용도 기록한다. 서로 다른 공급자 자료를 썼다면 분석 능력 비교가 아니라 운영 비교로 분류한다.

사람 검토자는 A/B를 무작위 순서로 받아 위 기준으로 비교한다. 모델 심사는 보조 의견일 뿐 최종 승인이 아니다.
치명 오류나 원문 충실성이 악화되면 채택하지 않는다. 복잡성 증가는 대안 구별·수정 조건의 개선 사례로 정당화한다.
차이가 없으면 더 단순한 기준선을 유지한다. 프롬프트를 바꾸면 영향받는 사례를 다시 평가하고 버전을 올린다.

## 이번 PR의 승인 기록

현재 `human_review=pending`, `fixture_preparation=not_started`, `model_evaluation=not_executed`다.
사람 검토자는 다음 세 결정을 확인한다: 자료가 부족하면 방향을 보류하는 규칙,
주요 논점 최대 3개와 강한 대안을 비교하는 방식, 치명 오류 0건 및 모든 항목 1점 이상·합계 7/8 이상 기준.
승인은 PR 댓글 또는 명시적 사용자 지시로 기록한다. 에이전트가 스스로 사람 승인을 기입하지 않는다.
